# template_name

One sentence: what this annotator reports.

**Output:** [schema.json](schema.json). What each field means.

**How:** the method, in a few sentences. For a model judge: the model, the prompt, its hash, and what the model sees.

**Good at:** the cases where you checked it and it was right.

**Weak at:** the cases where it is wrong or cannot decide, and what it reports then.

**Checked on:** which traces you read by hand to check it, and how many.
